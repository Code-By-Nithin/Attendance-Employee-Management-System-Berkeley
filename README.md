# Attendance & Employee Management System – Berkeley

Designed and developed an internal employee management solution for Berkeley to streamline workforce operations and attendance monitoring. The system enables employee record management, attendance tracking, shift scheduling, payroll support, and report generation. Built to improve operational efficiency, reduce manual errors, and simplify staff monitoring for large-scale workforce management across departments.

## About

This is a pure PHP, HTML, JavaScript, and CSS project for managing employees and attendance. It includes features for:

- Employee record management
- Attendance logging and tracking
- Shift scheduling and duty roster management
- Report generation for attendance and payroll
- Internal staff monitoring and performance tracking

## Note

This project is intended to run on a local PHP web server with a MySQL database. It is not a compiled application; instead, it uses standard web technologies and server-side PHP for backend logic.

## How to run this project

1. Install a local web server stack such as XAMPP, WAMP, or Laragon.
2. Create a MySQL database for the project.
3. Import the `berkeley_emp-management.sql` database file into your new database.
4. Copy the project folder into your local web server's document root, for example:
   - `C:\xampp\htdocs\berkeley_attendance`
   - `C:\wamp64\www\berkeley_attendance`
5. Update the database connection settings in `connection.php` with your MySQL host, username, password, and database name.
6. Open the project in your browser:
   - `http://localhost/berkeley_attendance`
7. Log in or navigate to the dashboard based on the project setup.
